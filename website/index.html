PocketCoder is a free, mobile-first code editor and on-device dev environment — a community-built, MIT-licensed project focused on privacy, offline execution, and learning from your pocket.

View on GitHub Get Involved

Key features

  • Mobile-optimized editor

    A lightweight code editor built for touch screens and small displays.

  • Live web preview

    Preview HTML/CSS/JS projects instantly, right inside the app.

  • On-device Python

    Run Python scripts locally via Pyodide — no server required.

  • Optional local AI assistance

    Bring your own model for on-device, offline code suggestions (llama.cpp/ggml) — your code never leaves your device.

  • P2P collaboration

    CRDT-based real-time editing (Yjs + WebRTC) for privacy-first pairing.

  • Plugin architecture

    Extend PocketCoder with community-built plugins and runtimes.

Where we're headed

  1. MVP-1 — Web preview & project management
  2. MVP-2 — Local language runtimes (Pyodide, WASM)
  3. MVP-3 — Optional local AI assistance (alpha)
  4. MVP-4 — P2P collaboration (Yjs + WebRTC)
  5. MVP-5 — Accessibility, polish, and lessons
