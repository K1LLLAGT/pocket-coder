Privacy Policy

Last updated: 2026

PocketCoder is built to be privacy-first by design. This page describes what happens to your code and data when you use the app, and what (very little) this marketing site collects.

The PocketCoder app

  • Your code stays on your device. Projects, files, and settings are stored locally on your phone or tablet — PocketCoder does not upload your code to any server by default.
  • On-device execution. Language runtimes (such as Pyodide for Python) run entirely inside the app's sandboxed webview. No code is sent off-device to run it.
  • Optional local AI assistance. Any AI code suggestions use a model file you supply yourself and run via an on-device inference bridge. Your code and prompts are not sent to a remote inference server.
  • Optional P2P collaboration. Real-time collaboration features use direct peer-to-peer connections (WebRTC) for the editing session itself. A signaling/relay server may be used only to help peers find each other, and does not see your file contents.
  • Plugins. Community plugins run in a sandboxed context. See SECURITY.md for details on the plugin and model trust model.

This website (pocket-coder.ai)

This marketing site is a static page with no backend, no accounts, and no tracking scripts. Your static host provider (e.g. Netlify, Vercel, GitHub Pages, or Cloudflare Pages) may collect standard server access logs (such as IP address and requested URL) as part of normal web hosting — PocketCoder does not add any additional analytics or third-party trackers on top of that.

Questions

This project is community-run and provided as-is. If you have questions about privacy or want to report a concern, please open an issue on GitHub.
