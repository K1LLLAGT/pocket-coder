# Code of Conduct

This project follows the Contributor Covenant (version 2.0). We expect all contributors to be respectful and inclusive. Unacceptable behavior (harassment, discriminatory language, doxxing) will not be tolerated.

Please read the full Contributor Covenant: https://www.contributor-covenant.org/version/2/0/code_of_conduct/

Report issues to the maintainers or open a private discussion if you experience any incidents. Security-specific reports should follow [SECURITY.md](SECURITY.md) instead.
